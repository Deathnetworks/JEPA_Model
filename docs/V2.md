**Porting Approach & Recommendations**:

**Which CUDA kernel is "best" to port?**
- The **selective scan kernel** from the original `state-spaces/mamba` (or its maintained forks) is the most critical and widely regarded as the reference.
  - It implements the core SSM recurrence (`B`, `C`, `dt`, selective parameters) with fused operations.
  - Mamba-2 SSD (State Space Duality) kernels are also excellent — they are often more parallelizable.
- Start with the **Mamba-1 selective scan** (more mature) then upgrade to Mamba-2 if needed.

**How to Port It**:
1. **Study the CUDA source**:
   - Key files: `selective_scan_cuda.cu`, `causal_conv1d_cuda.cu` in `mamba-ssm`.

2. **SYCL Porting Strategy**:
   - Use **Intel oneAPI Base Toolkit** + **SYCL** (DPC++).
   - Translate CUDA `__global__` kernels to SYCL `sycl::kernel` or `parallel_for`.
   - Leverage **oneMKL** (Intel’s math library) for BLAS-like operations where possible.
   - Use `sycl::nd_range` for thread/block mapping (similar to CUDA grid/block).

3. **Implementation Steps**:
   - Create `src/kernels/sycl_selective_scan.cpp` (or `.sycl`).
   - Write a thin PyTorch C++/SYCL extension (use `torch.utils.cpp_extension` with SYCL compiler).
   - Start with a **naive parallel implementation** of the selective scan recurrence, then optimize.

**Things to Optimize Specifically for Intel Arc Pro B70 (32GB)**:
- **Memory Hierarchy**: Arc has good L3 cache and large VRAM — design kernels to maximize coalesced global memory access and reuse via shared/local memory (SYCL `local_accessor`).
- **Vectorization**: Use Intel’s subgroup operations and `sycl::vec` for FP16/BF16-heavy workloads (your model uses bfloat16).
- **Xe Matrix Extensions (XMX)**: If possible, map matrix multiplies in the SSM to XMX hardware (similar to Tensor Cores). oneAPI has extensions for this.
- **Occupancy & Launch Config**: Tune work-group sizes (e.g., 32/64/128) for Arc’s execution units. Avoid register pressure.
- **Mixed Precision**: Heavy use of BF16 + FP32 accumulation.
- **Batch + Sequence Parallelism**: Leverage your 32GB to run larger effective batches or longer chunks.
- **Kernel Fusion**: Fuse as many operations as possible (conv1d + selective scan + activation) to reduce memory traffic.
- **Profiling Tools**: Use **Intel VTune**, **oneAPI Advisor**, and **SYCL Debug** extensively.

**Potential Challenges & Mitigations**:
- **Numerical Stability**: SSMs are sensitive to recurrence — match CUDA floating-point behavior exactly (use same discretization, clamping, etc.).
- **Performance Parity**: Initial port will be slower — focus on correctness first, then iterate optimizations.
- **Build Complexity**: Provide a CMake or setup script that detects XPU and compiles the SYCL extension.
- **Fallback Path**: Always keep the pure PyTorch (or legacy loop) version as default when SYCL kernel is unavailable.
- **Testing**: Small sequences → long sequences → full training step. Compare outputs bit-for-bit where possible against CUDA version.

3. **Sample SYCL Kernel Skeleton** (Selective Scan Core)

```cpp
// selective_scan_kernel.sycl
#include <sycl/sycl.hpp>
using namespace sycl;

template<typename scalar_t>
void selective_scan_kernel(
    sycl::queue &q,
    scalar_t* __restrict__ x,           // [batch, seqlen, dim]
    scalar_t* __restrict__ dt,
    scalar_t* __restrict__ A,
    scalar_t* __restrict__ B,
    scalar_t* __restrict__ C,
    scalar_t* __restrict__ out,         // output
    scalar_t* __restrict__ state,       // optional hidden state
    int batch, int seqlen, int dim, int dstate) 
{
    q.submit([&](handler &h) {
        // Local memory for tiling / caching
        accessor<scalar_t, 1, access::mode::read_write, access::target::local> 
            tile(sycl::range<1>(256), h);   // tune size

        h.parallel_for(nd_range<2>(
            range<2>(batch, seqlen),   // global range
            range<2>(1, 128)           // work-group size — tune for Arc
        ), [=](nd_item<2> item) {
            int b = item.get_global_id(0);
            int t = item.get_global_id(1);
            int lid = item.get_local_id(1);

            if (t >= seqlen || b >= batch) return;

            // Per-thread computation of selective SSM step
            scalar_t dt_t = dt[b * seqlen * dim + t * dim + /*channel*/];
            scalar_t a = A[/*...*/];
            scalar_t b_val = B[b * seqlen * dstate + t * dstate + /*...*/];
            scalar_t c_val = C[b * seqlen * dstate + t * dstate + /*...*/];

            // Discretization (same as CUDA version)
            scalar_t decay = sycl::exp(-dt_t * a);
            scalar_t x_t = x[b * seqlen * dim + t * dim + /*channel*/];

            // Core recurrence (simplified — expand for full multi-channel)
            scalar_t h_new = decay * /*prev_h*/ + (1.0f - decay) * b_val * x_t;  // or exact Mamba formula

            out[b * seqlen * dim + t * dim + /*channel*/] = h_new * c_val;

            // Write back state if maintaining across sequence
        });
    });
}
```

**Key Optimizations for Arc Pro B70**:
- **Work-group sizing**: Experiment with 32/64/128 threads per group (matches Xe cores).
- **Tiling & Local Memory**: Cache `A`, `B`, `C` parameters per work-group to reduce global memory pressure.
- **Vectorization**: Use `sycl::vec<scalar_t, 8>` or 16 for BF16 loads.
- **XMX Usage**: Map matrix-vector multiplies (common in SSM) to `sycl::ext::oneapi::experimental::matrix` APIs if available in your oneAPI version.
- **Memory Coalescing**: Ensure consecutive threads access consecutive memory.
- **BF16 Emphasis**: Use `sycl::bfloat16` heavily with FP32 accumulation for stability.
- **Launch Parameters**: Tune grid/block via profiling (VTune) for your typical chunk size (4096 tokens).

4. **PyTorch Binding** (C++ Extension)

```cpp
// sycl_selective_scan.cpp
#include <torch/extension.h>
#include <sycl/sycl.hpp>

torch::Tensor selective_scan_sycl(...) {
    auto q = sycl::queue(sycl::gpu_selector_v);  // or XPU specific
    // Call kernel wrapper
    selective_scan_kernel(q, ...);
    return output_tensor;
}

PYBIND11_MODULE(TORCH_EXTENSION_NAME, m) {
    m.def("selective_scan", &selective_scan_sycl, "Selective Scan (SYCL)");
}
```
